# Security

Report security issues privately to the repository maintainers through the host's
private vulnerability reporting channel when available. If it is unavailable,
request a private contact without posting exploit details or sensitive data in a
public issue. Never submit real customer data, credentials or browser sessions.

This is a local release candidate. Experimental clients are not supported production
security boundaries. See docs/verification.md and local-agent/README.md for precise
coverage and known limitations. Browser-visible configuration is public; identity
and authorization belong to auth-go, the gateway and backend services.
